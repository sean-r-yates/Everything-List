# Listy Android

This Android app is a native offline Listy app with its own SQLite database.

Build output:

```text
../dist/Listy Android.apk
../dist/Listy Android 1.6.9.apk
```

Install the APK directly on Android. The app can add shopping items, games, shows, and locations from links, accept links from Android's Share menu, detect likely duplicates, edit item details manually, keep profiles, move deleted items to Bin, restore/clear Bin items, and show local sync history.

Android and Windows keep independent local databases. Export/import sync bundles can merge changes between them, and Bluetooth sync can exchange those bundles directly with the PC app.
